# ✝️ FAITHQUEST BIBLE

### 📖 Interactive Bible Quiz Web Application

**FAITHQUEST BIBLE** is a Java-based web application designed to help users grow spiritually while testing their knowledge of the Bible through engaging quizzes.

Built with a focus on simplicity, learning, and faith-based engagement, this app provides an interactive platform for Christians, students, and Bible enthusiasts.

## 🧠 Features

* 📚 Multiple Bible quiz questions
* 🎯 Score tracking system
* ⏱️ Timed or untimed quizzes (optional)
* 🔄 Randomized questions
* 📊 Instant results and feedback
* 🧑‍🤝‍🧑 User-friendly interface

## ⚙️ Installation & Setup

### 🔹 Prerequisites

* Java JDK 8 or higher
* Maven installed
* Git

---

### 🔹 Clone the Repository

```bash
git clone https://github.com/your-username/faithquest-bible.git
cd faithquest-bible
```

---

### 🔹 Build the Project

```bash
mvn clean install
```

---

### 🔹 Run the Application

```bash
java -jar target/faithquest-bible.jar
```

---

### 🔹 Access in Browser

```
http://localhost:8080
```
